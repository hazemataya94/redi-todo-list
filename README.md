# Getting Started

## Create python virtual environment
```
python -m venv .venv
```

## Activate python virtual environment
```
source .venv/bin/activate
```

## Install requirements
```
pip install -r requirements.txt
```

## Run the applicaation web server (start the API)
```
python main.py
```

## Import the postman collection `TodoList.postman_collection.json` and start experimenting
